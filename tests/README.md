# 本地验证

```powershell
python -m unittest -v
node tests/dashboard.test.cjs
```

Python 检查采集结构、32 条语言对照案例、来源身份归属、模型输出验证、上下文复审、失败回退、去重和 HTML 转义。模型传输测试只使用本地模拟服务器，不需要 API Key。

Node 检查多标签计数、占比分母、筛选与累计数据更新。没有依赖第三方图表库。

演示数据由这些合成案例组成，不对应任何真实账号。测试通过不是对真实世界识别准确率的声明。

`test_topics_space.py` 另外检查公共议题句式、隐语误报对照、话题证据来源、无关楼中楼隔离、匿名空间分页和作者归属、置顶与部分失败、412 / 接口变更 / 取消，以及 Windows 中文和空格路径的打开方式。空间接口通过合成夹具检查，不代表实网始终可用。Node 测试验证待确认话题不计入圆环，其他人的空间留言不改变本人标签计数。

`test_expressions.py` 检查隐晦性请求、谐音和表情组合、引用与正常活动反例、多义短句待确认、同房间时间窗口、重复文本与普通相邻发言隔离、来源解释弱隐语时的变更轨迹、辱骂与医学用语区分、type 11 评论归属、历史直播上下文限制及空 HTML 元数据。Node 测试同时检查“含义待确认”筛选和风险计数隔离。所有新增测试使用通用句式和合成记录。
