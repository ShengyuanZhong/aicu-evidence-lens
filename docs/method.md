# 方法选择与验证边界

旧版本用“喜欢、谢谢”等正面词计算积极占比，同时用另一个词表找风险，两个判断会互相矛盾。v2 删除了情绪词打分：`[喜欢]`、`[打call]`、`[doge]` 都不作为友好或无风险证据。

## 调研到的可用方向

| 资源 | 能提供什么 | 本项目的用法 |
| --- | --- | --- |
| [COLD / roberta-base-cold](https://github.com/thu-coai/COLDataset) | 中文冒犯检测数据与公开分类器；训练标注以二分类为主，测试集区分攻击个人、群体和反偏见等情况 | 可作为未来本地召回模型的候选，当前没有安装或调用该模型。仅靠通用冒犯分数不足以产生本项目的细分标签 |
| [ToxiCN，ACL 2023](https://aclanthology.org/2023.acl-long.898/) | 分层分类、直接与间接冒犯表达 | 借鉴分层和隐含表达意识，区分表达类别与待核查状态 |
| [STATE-ToxiCN，ACL 2025](https://aclanthology.org/2025.findings-acl.532/) | 对象、论述和文本片段层面的细粒度识别，也研究中文有害俚语 | 要求模型返回对象、标签、原文片段和简短依据；用代码校验片段确实在原文中 |

这些是方法设计参考，不代表本项目复现了论文结果。没有下载、训练或重新分发这些数据集；不同数据集的授权与使用条件应在将来使用时单独核对。

## v2 流程

1. 采集并规范化记录，按可用记录 ID 或来源、时间、文本指纹去重。原始记录单独保留。
2. 离线规则做候选检索：移除表情对匹配的干扰、识别组合表达、按分句限定否定作用域。未命中是 `unreviewed`，不是“安全”。
3. 配置模型后，默认对全部记录分批语义审核，包括规则未命中的记录。返回固定目录内的标签、对象、证据片段、状态、是否需要上下文。缺记录、未知标签、伪造引用或 JSON 错误均保留原候选并记录失败。
4. 对需要上下文且优先级达到阈值的记录，访问 Bilibili 原网页；视频补查标题、简介、分区；评论补查根评论及第一页回复。单条最多约三次请求，受记录预算、超时及访问限制约束。
5. 来源中只有评论 ID 与 UID 同时匹配才标记为查询账号发言，其他内容明确属于其他或未确认作者。网页正文中的指令不执行。
6. 有可用上下文时，让模型再审同一条记录，保留前后判断。没有模型时只展示来源证据，不自动改变标签。
7. 汇总逐条结果产生账号发言评述，显示模型覆盖与来源缺失；最终评述的证据数量上限不等于逐条审核的数量上限。

模型默认分批读取全部记录会产生按数据量增长的调用量，可通过 `--llm-record-limit` 控制。这里没有经过校准的概率，因此不显示“95% 可信”之类数字。

## 统计口径

对筛选范围内的每条发言，同一标签只计一次；多个不同标签分别计数。

`标签份额 = 该标签计数 / 全部可见标签计数之和`，圆环扇区和条形长度使用这一口径。假设 A 出现 8 次，B 出现 2 次，则 A 为 80%，B 为 20%。

`发言覆盖 = 该标签计数 / 筛选后的发言数`，在标签悬停提示中显示。由于允许多标签，各标签覆盖率之和可以超过 100%。未打标签的记录仍保留在发言总数和证据列表中。

## 当前验证及局限

`tests/cases.json` 是 32 条人工构造的回归案例，覆盖用户指出的原句、变体、正面表情、局部否定、性教育相关对照词、游戏争论及政治话题。它用于防止已知错误重现，不能代表真实 Bilibili 数据上的准确率。

语义模型的供应商和具体模型尚未选择，所以当前只验证了请求协议、结构校验、失败回退和上下文复审流程，未验证真实模型分类效果。后续需用用户复核的真实样本建立独立评估集，分别测各标签的误报与漏报。

网页核查不观看视频画面、不做音频转写，也不能保证找到已删除评论、动态加载内容或第一页以外的回复。直播间链接只能定位房间，不能复原当时的直播。来源标题不能单独证明某句话是玩笑或骚扰；这些情况下保留待核查状态。

离线规则仍会漏掉新梗和隐晦表达。建议在正式筛选前接入模型并人工复核高风险证据。报告判断的是可观察发言，不推断心理状态、性取向或政治立场。
